# Чем расшифровывать: сравнение сервисов

Справка на сентябрь 2026. Цены взяты из официальных прайсов, а не из
обзоров: у агрегаторов встречаются цифры, завышенные в десятки раз.

## За час записи встречи (моно)

| Вариант | Цена за час | Разделение по голосам | Где обрабатывается |
|---|---|---|---|
| **OpenAI** `gpt-4o-transcribe-diarize` | ~$0.36 | в коробке | США |
| **Yandex SpeechKit**, асинхронный | ~36 ₽ | есть, API v3 | РФ |
| **Yandex SpeechKit**, отложенный | ~9 ₽ | есть, API v3 | РФ |
| **SaluteSpeech** (Сбер), асинхронный | ~36 ₽ | есть | РФ |
| **GigaAM v3** (Сбер, MIT), своё железо | 0 ₽ | нет, нужен pyannote | своё |

По умолчанию используется OpenAI: он единственный даёт расшифровку
и разделение по голосам одним запросом, без своего железа.

## Важная дата: 26 февраля 2027

OpenAI объявила снятие `whisper-1`, `gpt-4o-transcribe`,
`gpt-4o-mini-transcribe` и **`gpt-4o-transcribe-diarize`** — последняя
и есть та, что умеет разделять говорящих.

Замена предложена одна, `gpt-transcribe`: она дешевле и точнее, но
**разделения по голосам у неё нет** — это проверено запросом, а не
прочитано в анонсе. После февраля 2027 у OpenAI не остаётся модели,
которая скажет, кто говорил.

Выбирать придётся из трёх путей:

- мириться с брифом без имён говорящих;
- перейти на Yandex SpeechKit — разделение есть, данные остаются в РФ;
- считать на своей видеокарте, см. [local-stt.md](local-stt.md).

## Yandex SpeechKit, отложенный режим

Втрое дешевле OpenAI и не требует своего железа. Но:

- **нет гарантии по времени** — этим и объясняется цена; для брифа
  через пятнадцать минут после встречи не годится, для ночной
  обработки длинных записей годится вполне;
- нужен сервисный аккаунт Yandex Cloud и загрузка файла в Object
  Storage: прямой отправки файла нет;
- тарификация идёт по двухканальному аудио, количество каналов
  округляется до чётного — моно считается как два канала.

## Бесплатное у Сбера

Freemium у SaluteSpeech (100 минут в месяц) закрыт для новых
пользователей с 15 июля 2026. Для юрлиц действует минимальный платёж
15 000 ₽ в месяц независимо от объёма.

Бесплатными у Сбера остаются **открытые модели**: GigaAM v3 под
лицензией MIT, на русском языке точнее Whisper. Разделения по голосам
в ней нет — его даёт pyannote, которую ставят отдельно.

## Как сменить расшифровку

Распознавание живёт в одной функции `transcribe()` в
`poc/pipeline/brief.py`. Подменить в ней бэкенд — работа на день,
а не переписывание сервиса.
